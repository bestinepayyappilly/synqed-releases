# Synqed — downloads

Your Android phone, on your Mac. Calls, messages, notifications, clipboard and
files move between your phone and your Mac over your own Wi-Fi — no cloud, no
account, no relay server.

**[Download the Mac app](https://github.com/bestinepayyappilly/synqed-releases/releases/latest)** · [synqed.studio](https://synqed.studio)

Synqed is two apps. This one is the Mac half; the Android half is on Google
Play. You need both, on the same network.

## Requirements

- macOS 14 or later
- An Android phone (Android 13 or later) with the Synqed app
- Both devices on the same Wi-Fi network

## Installing

Download the `.dmg`, open it, and drag Synqed to Applications. The app is signed
with a Developer ID certificate and notarised by Apple, so it opens without a
Gatekeeper warning.

## Why this repo has no source

Synqed's source is private. This repo exists only to host release binaries,
because GitHub Releases is a better home for them than a web host: the files are
versioned, immutable, and free to download at any volume.
